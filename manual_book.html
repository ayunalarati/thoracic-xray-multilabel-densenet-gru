Gambaran Umum Sistem

Aplikasi CITRA X-RAY merupakan aplikasi web berbasis Python Flask untuk klasifikasi multi-label 15 penyakit toraks pada citra rontgen dada (Chest X-Ray). Aplikasi ini dirancang sebagai alat bantu pendukung keputusan klinis (Clinical Decision Support System) bagi tenaga medis, khususnya radiolog, untuk memperoleh hasil analisis citra rontgen secara lebih cepat dan akurat melalui teknologi kecerdasan buatan.

🌐 Aplikasi Telah Di-Hosting Online
Sistem CITRA X-RAY telah di-deploy dan dapat diakses secara publik melalui internet. Pengguna cukup membuka browser dan mengakses URL berikut tanpa perlu instalasi apapun:
🔗 https://citra-xray.example.com
(URL akan diperbarui sesuai domain hosting final)

Secara umum, aplikasi bekerja dengan menerima citra rontgen toraks (Chest X-Ray) sebagai masukan. Citra tersebut kemudian diproses oleh backend Flask menggunakan model deep learning. Sistem menggunakan arsitektur hybrid CNN+RNN dengan menggabungkan DenseNet121 (sebagai backbone ekstraksi fitur visual) dan GRU (Gated Recurrent Unit) sebagai sequential head untuk menangkap relasi spasial antar region anatomis pada peta fitur 7x7. Penggabungan tersebut bertujuan menghasilkan representasi fitur yang lebih kaya dalam menangkap karakteristik morfologi dan distribusi spasial kelainan radiologis toraks.

Hasil pemrosesan model ditampilkan kepada pengguna dalam bentuk tabel probabilitas 15 kelas penyakit, status deteksi (Terdeteksi / Normal), serta nilai performa model (AUROC Score) per kelas. Selain hasil klasifikasi, aplikasi menyediakan fitur Score-CAM yang menghasilkan visualisasi heatmap pada area citra yang paling berpengaruh terhadap keputusan model.

Alur Kerja Sistem

Citra Rontgen Toraks → Upload melalui Web UI → Backend Flask (Python) → Preprocessing (224x224)
→ DenseNet121 + GRU Hybrid → Prediksi Multi-Label 15 Kelas → Score-CAM → Hasil pada Web UI

Fungsi Utama Aplikasi

Input Citra X-Ray
Pengguna mengunggah atau memilih citra rontgen dada yang akan dianalisis.
Preprocessing Citra
Citra diubah ke resolusi 224x224 dan dinormalisasi sebelum masuk ke model.
Klasifikasi Multi-Label
Model DenseNet121+GRU menganalisis dan menghasilkan probabilitas 15 penyakit toraks.
Score-CAM Heatmap
Visualisasi area fokus AI pada citra rontgen untuk setiap kelas penyakit.
Tabel Diagnosis Lengkap
Tabel probabilitas, status deteksi, dan AUROC Score per kelas penyakit.
Lembar Ekspertise
Laporan temuan radiologis terstruktur yang siap cetak/ekspor PDF.
Catatan Penting: Sistem ini berfungsi sebagai second opinion dan alat bantu penapisan awal. Hasil prediksi AI tidak menggantikan diagnosis klinis oleh dokter radiolog.

Panel KananSisi kananHasil diagnosis AI: tabel 15 kelas penyakit, Score-CAM per penyakit, ekspertise

  • Judul aplikasi: CITRA X-RAY - Sistem Ekspertise Radiologi Toraks Terintegrasi
  • Indikator Model AI: DenseNet121+GRU (live status + Mean AUROC: 0.7111)
  • Pengaturan Tema: 4 opsi tema (Pastel Sage, Radiology Dark, Clinical Light, Ocean Teal)
  • Tombol Database: Riwayat rekam medis cloud (Supabase)
  • Tombol Cetak: Cetak lembar ekspertise radiologi

2 Upload Citra X-Ray Sendiri (Custom Input)

Selain preset, pengguna dapat mengunggah citra rontgen sendiri:

  • Klik "Buka File Citra": Klik tombol untuk membuka file explorer.

Setelah file dimuat, citra ditampilkan di area preview beserta nama file dan resolusi matriks (224x224).

3 Alat Radiologi (Window/Level & Kontras)

Setelah citra dimuat, pengguna dapat menggunakan toolbar radiologi:

  • Standar: Mode tampilan default tanpa modifikasi kontras.
  • Paru (Lung Window): Optimasi kontras untuk jaringan paru-paru.
  • Tulang (Bone Window): Optimasi untuk struktur tulang iga dan klavikula.
  • Balik Warna (Invert LUT): Membalik skala abu-abu.
  • Ganti File: Mengganti citra dengan file baru.
4 Mengatur Ambang Batas Klinis (Threshold)

Slider "Cutoff / Ambang Batas Klinis" mengatur sensitivitas deteksi:

  • Default: 0.20 (20%) - disesuaikan untuk menekan False Negative.
  • Rentang: 0.05 (sangat sensitif) hingga 0.50 (sangat spesifik).
Penjelasan: Threshold rendah (0.20) dipilih berdasarkan justifikasi klinis bahwa dalam CAD, lebih baik mendeteksi False Positive daripada melewatkan False Negative yang dapat berakibat fatal.
5 Menjalankan Analisis AI (Inferensi)

Tekan tombol biru "Analisis Citra X-Ray" di panel kiri. Proses di balik layar:

  1. Citra dikonversi ke tensor 224x224x3 dan dinormalisasi ke [0, 1].
  2. Model DenseNet121 mengekstrak peta fitur konvolusi (7x7x1024).
  3. Peta fitur di-reshape menjadi sekuens (49, 1024) dan diolah oleh GRU (256 unit).
  4. Layer Dense (256 - 128 - 15 neuron sigmoid) menghasilkan 15 probabilitas independen.
  5. Score-CAM dijalankan untuk kelas dengan probabilitas tertinggi.
6 Membaca Hasil Diagnosis (Panel Kanan)

Setelah analisis selesai, panel kanan menampilkan:

  • Badge Temuan Utama: Ringkasan penyakit utama yang terdeteksi.
  • Tabel 15 Kelas Penyakit Toraks: Nama penyakit, probabilitas (%), status (TERDETEKSI / NORMAL), dan AUROC Score.
  • Waktu Inferensi: Durasi total pemrosesan (dalam detik).

7 Visualisasi Score-CAM (XAI / Explainability)

Di panel tengah, tersedia 3 mode tampilan:

ModeDeskripsi
OriginalCitra rontgen asli tanpa modifikasi (grayscale).
HeatmapPeta panas Score-CAM murni. Warna merah/kuning = area kontribusi tinggi terhadap prediksi.
OverlayHeatmap transparan di atas citra asli. Mode paling informatif - memungkinkan korelasi area fokus AI dengan struktur anatomis.

Interaktivitas per penyakit: Klik baris penyakit tertentu pada tabel diagnosis, maka viewer akan memperbarui heatmap khusus untuk penyakit yang dipilih.

Slider Opacity: Geser slider untuk mengatur tingkat transparansi overlay heatmap (default: 45%).

8 Cetak Lembar Ekspertise Radiologi

Setelah analisis selesai, pengguna dapat mencetak Lembar Ekspertise Radiologi Terstruktur:

  1. Klik tombol "Cetak" (ikon printer) di header kanan atas.
  2. Lembar ekspertise akan dibuka dalam dialog cetak browser.
  3. Pilih "Save as PDF" atau langsung cetak ke printer.

Lembar ekspertise berisi:

  • Metadata subjek (Subject ID, Image Index, Demografi)
  • Uraian temuan radiologis terstruktur per regio anatomis
  • Tabel prediksi 15 penyakit beserta probabilitas dan AUROC
  • Kesimpulan AI (AI Impression) dan visualisasi Score-CAM
9 Riwayat Diagnosis (Database Supabase - Opsional)

Jika Supabase dikonfigurasi (mengisi SUPABASE_URL dan SUPABASE_ANON_KEY pada file .env), sistem akan:

  • Otomatis menyimpan setiap hasil diagnosis ke database cloud.
  • Menampilkan riwayat pemeriksaan melalui tombol "Database" di header.
  • Memungkinkan pemuatan ulang kasus dari riwayat ke viewer.
Catatan: Database bersifat opsional. Aplikasi tetap berfungsi normal tanpa konfigurasi Supabase.
Catatan Penggunaan: Sistem ini berfungsi sebagai second opinion untuk membantu radiolog, bukan menggantikan diagnosis klinis. Hasil prediksi harus tetap diverifikasi sesuai protokol medis. Mean AUROC model: 0.7111.
